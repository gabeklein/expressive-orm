Live rows over LISTEN/NOTIFY. `sync` installs an `expressive_notify()` trigger function and a trigger per table, which `pg_notify`s the `expressive_orm` channel with `{ table, op, id, row }` - the row omitted when the payload would pass 8000 bytes. `PGConnection` listens on a client of its pool, `PGLiteConnection` through PGLite's `listen`, from the first entity loaded until the connection is destroyed. Entities loaded through either follow changes made elsewhere. Triggers use `CREATE OR REPLACE TRIGGER` (Postgres 14+).

- Construct connections with `PGConnection.new(using, config)` and `PGLiteConnection.new(using, dataDir | pglite, options)`.
- An incrementing `id` renders `GENERATED BY DEFAULT AS IDENTITY`, so an explicit id inserts as on SQLite and memory. The sequence does not advance past an explicit id.
- A `timestamp` without time zone read as a string is UTC, as when read as a `Date`.
